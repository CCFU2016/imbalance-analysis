# Imbalance Analysis

Dutch (TenneT) and French (RTE) imbalance prices compared with day-ahead prices (ENTSO-E), 2021–2025, as static
HTML infographics with a built-in test page.

```bash
python3 serve.py   # then open http://localhost:8765/infographic_dayahead.html
```

`infographic_dayahead.html` can also be opened directly in a browser; only its "Run Tests Now" button needs the
server. See [CLAUDE.md](CLAUDE.md) for the data, scripts and how to add newer data.
